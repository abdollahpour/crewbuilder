# CrewAI Crew

Multi-agent CrewAI project generated by Crew Builder.

## Setup

1. Unzip the downloaded archive.
2. Copy `.env.example` to `.env` and set your LLM provider API keys.
3. Install dependencies:

```bash
crewai install
```

Or with uv:

```bash
uv sync
```

## Run

Prompt for a request and let the coordinator delegate work to agents dynamically:

```bash
crewai run
```

Or run the flow directly:

```bash
python main.py
```

The coordinator receives your input, assigns subtasks to team members, and writes the final report to `output/report.md`.

Generated layout:

- `<agent_name>.jsonc` — agent configs (plus `coordinator.jsonc` and `crew.jsonc`)
- `knowledge/<name>/` — shared FAISS indexes; agents that use them get a `knowledge_search` tool
- `skills/<name>/SKILL.md` — shared skills referenced from agent configs
